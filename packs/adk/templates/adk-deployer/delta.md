# ADK Deployer Pack Delta (`packs/adk`)

1. Operate strictly with `--service-account adk-deployer` inside the disposable Sandbox project only.
2. Follow `google-agents-cli-deploy` and `google-agents-cli-publish` using Dockerfile-first container deployment (`agents-cli deploy --deployment-target agent_runtime` or `cloud_run`). Build PR container images strictly inside `sandbox_project_id` using `sandbox_builder_sa_email` and `sandbox_artifact_registry_url` (never the Hub project registry). Never set reserved `GOOGLE_CLOUD_PROJECT`, `GOOGLE_CLOUD_QUOTA_PROJECT`, or any `GOOGLE_CLOUD_AGENT_ENGINE_*` key in Agent Engine `deploymentSpec.env` (HC-11 F4). For Gemini 4 models on Agent Engine, set `GOOGLE_CLOUD_LOCATION=global` for inference and non-reserved `ADK_AGENT_ENGINE_REGION=<region>` for regional `VertexAiSessionService` sessions (HC-11 F5).
3. Verify the root `Dockerfile` (`uvicorn app.fast_api_app:app`, non-root `USER`), `agents-cli-manifest.yaml`, and pinned `pyproject.toml` before every Sandbox deployment, passing `APP_URL` on Cloud Run so the dynamic A2A `AgentCard` advertises the real HTTPS URL.
4. Prefix every ephemeral Sandbox deployment and Gemini Enterprise registration with `[CI] PR-<number>-<sha7>`.
5. Validate `ge_manifest.json` and export `dist/ge-export/` via `python3 /opt/adk-factory/ge_export.py export`.
6. Run `python3 /opt/adk-factory/ge_export.py preflight --manifest ge_manifest.json` before any live Gemini Enterprise registration. If preflight returns `NO_PROJECT_LICENSE` or `AUTO_REGISTER_DISABLED` (exit code 2), skip `agents:create` retries, keep `dist/ge-export/`, and report the exact license remediation. When preflight returns `READY`, prefer `ge_export.py patch --agent-name <sandbox-agent>` over per-PR `POST` creation to avoid daily Gemini Enterprise 429 quotas.
7. Never register or mutate DEV, HML, or PRD Gemini Enterprise apps from an agent container.
8. Record every created ephemeral resource in `/scion-volumes/scratchpad/sandbox-ledger.jsonl`.
